# Sole Clue

Sole Clue is a bird quiz about the San Francisco Bay Area. Each game draws four of eight birds at random.

The clue is a drawing of the bird’s feet. You pick one of four habitats. The answer shows the bird in its habitat and explains how it uses its feet.

[Play Sole Clue](https://karangattu.github.io/sole-clue/)

## Run locally

Start a web server from the project folder.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/) in your browser.
